# Intelligent Scam Risk Assessment System

An FYP project exploring how machine learning can help users assess the risk of suspicious text messages.

## Problem Statement

Users may struggle to distinguish scam messages from legitimate messages because scammers use convincing language, urgency and social engineering tactics. A classification result alone may not adequately explain why a message is considered suspicious. This project proposes a system that combines machine learning and rule-based indicators to assess scam risk and uses a Large Language Model (LLM) to generate understandable explanations. It also explores extracting text from uploaded images so that image-based messages can be analysed.

## Specialized Technology

Primary Technology : Machine Learning (ML)

Supporting Components : Natural Language Processing (NLP), Large Language Models (LLM), Optical Character Recognition
